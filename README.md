# Incident Handler's Journal

A cybersecurity portfolio project documenting security incident scenarios using an incident handler's journal.

## Overview
This repository contains my first journal entry, based on a ransomware incident at a small U.S. primary-care health clinic. The incident began with phishing emails carrying a malicious attachment, which led to encrypted files and a ransom demand.

## Scenario Summary
- **Who:** Organized hacker group targeting healthcare and transportation
- **What:** Ransomware encrypted critical files; ransom note demanded payment
- **When:** Tuesday, ~9:00 a.m.
- **Where:** Small U.S. primary-care clinic
- **Why:** Phishing attachment installed malware, enabling ransomware deployment (financial motive)

## Skills Demonstrated
- Incident documentation
- Applying the 5 W's framework
- Phishing and ransomware attack analysis
- Identifying prevention and response gaps (backups, training, filtering, segmentation)
